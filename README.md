# Portfolio — Ali Can Öner

Site statique, sans dépendance ni étape de build : `index.html`, `css/style.css`, `js/main.js`
et les aperçus WebP dans `assets/`.

- Ouvrir `index.html` dans un navigateur suffit pour le voir en local.
- Déploiement : le projet Vercel est relié à ce dépôt GitHub, un push sur `main` déploie automatiquement en production. En secours : `vercel deploy --prod` depuis ce dossier.
- Les aperçus des projets sont des captures des sites en production (1440×900), converties en WebP.
